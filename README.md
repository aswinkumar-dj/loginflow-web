# 🔐 LoginFlow – Next.js Firebase Auth App

A modern authentication system built using **Next.js, Firebase Authentication, Zustand, n8n automation & TailwindCSS**.

Users can:

✔ Create an account  
✔ Login with email/password   
✔ Redirect to a protected dashboard  
✔ Have their name stored via Zustand state  
✔ Trigger an n8n automation on signup (welcome email + Google Sheets entry)

---

## 🚀 Tech Stack
 
- Next.js (App Router)  
- Firebase 
- Zustand (Global user state)  
- Tailwind CSS  
- React Icons
- React Bits (Background Component)

---

## 📌 Features

✔ Responsive UI design  
✔ Sign Up / Login  
✔ Google Sign-In Authentication  
✔ Protected Dashboard Route  
✔ Zustand global user store  
✔ API trigger for n8n workflow
